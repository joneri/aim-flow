# AIM Flow local intake reference

## Typed local task

Local intake is explicitly separate from project discovery. The task and project profile are bound by hashes to the intended repository, source and requested effect. Preview does not read the private API credential or dispatch a model request.

A real dispatch requires the separately reviewed project grant, original shared budget history and exact-intent consent. Source-check evidence cannot be treated as application-build or product acceptance. See [installed local intake](aim-ci-install.md#installed-local-task-intake) for the command contract and [Beta scope](BETA-SCOPE.md) for limits.
