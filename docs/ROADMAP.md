# Roadmap

AIM Flow aims to make the route from an intention to verified delivery repeatable across real repositories. The following are directions, not shipped features or delivery commitments.

## Next

- Complete an independently reviewed real-project source-check pilot.
- Simplify repeatable operator setup without weakening input and permission checks.
- Improve the explanation of unsupported workflows and missing prerequisites.

## After evidence supports expansion

- Broader project-specific validation and artifact contracts.
- Qualified browser/testing adapters and more runtime/platform coverage.
- Explicit repository-specific review, CI, PR and release integrations.
- Reviewed multi-user governance and stronger runtime-enforcement evidence.

A new supported path needs real evidence and clear admission rules. A larger feature list alone does not make it supported.
