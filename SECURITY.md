# Security and operational boundaries

AIM Flow Beta is intended for trusted, reviewed project code. Do not treat its container settings as a qualified hostile-code sandbox or an enterprise security guarantee.

Do not include credentials, customer data, private source or raw operator journals in public issues. For a security concern, contact the repository owner privately using a channel you already trust. No private-reporting endpoint is claimed until one is configured.

Keep archive and executable pins, exact input identities and original journals. Unknown effect outcomes require reconciliation; do not retry blindly or reset budgets to bypass limits. Installation and preview do not authorize model access, execution, PRs, merges or deployment.

The website is static and has no analytics or submission backend. GitHub still handles normal hosting requests under its own terms.
